# 👽 AlienOS

**AlienOS is a custom gaming-focused Linux distribution based on Bazzite.**

Built for gaming, streaming, and just works™ out of the box.

---

## 🚀 What is AlienOS?

AlienOS is a derivative of [Bazzite](https://github.com/ublue-os/bazzite) by ublue-os / Universal Blue, reimagined with custom Alien branding, wallpapers, and optimizations.

Bazzite is built on top of Fedora Atomic Desktops - so you get the stability of Fedora with the gaming power of SteamOS.

### Features
- 🎮 Pre-installed Steam, Lutris, Heroic
- 👽 Custom AlienOS branding & wallpapers
- 🚀 Nvidia / AMD ready
- 🎯 Optimized for handhelds, desktops, HTPC
- 🔒 Atomic & immutable - unbreakable system

1. Download ISO
2. Flash to USB with Fedora Media Writer / Balena Etcher
3. Boot from USB
4. Install
